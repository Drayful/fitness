# YUMN — Flutter + Laravel

В репозитории находятся мобильный прототип и API. Полная экосистема из ТЗ ещё не реализована. Текущий статус, исправления и ограничения: [аудит проекта](docs/project-audit.md). [Вопросы производителю](docs/manufacturer-questions.md).

Размещение Laravel рядом с существующим сайтом и подключение регистрации мобильного приложения описаны в [инструкции для сервера](docs/server-registration-setup.md). Она рассчитана на `/var/www/ella_mobile` и публичный IP `80.242.213.87`, без нового домена.

- `backend/`: Laravel API, авторизация, тренировки, отдельные показания пульса, наблюдения сна и экспериментальные расчёты.
- `mobile/`: Flutter, BLE-интеграция с семействами SDK V8/2208A и отправка измерений и итогов тренировок.

## Локальный запуск

### Backend

Требования: PHP 8.4+, Composer, драйвер выбранной БД. `.env.example` настроен на PostgreSQL: укажите собственные реквизиты и создайте БД перед миграциями.

```powershell
cd backend
composer install
Copy-Item .env.example .env
# Настройте DB_* в .env.
php artisan key:generate
php artisan migrate
php artisan serve
```

`Copy-Item` и `key:generate` нужны только при первой настройке. Для существующего окружения сохраняйте `.env` и APP_KEY.

### Mobile

Проверено на Flutter 3.41.6 / Dart 3.11.4. Android minimum SDK 23. Для iOS требуется macOS/Xcode, provisioning и проверка Keychain Sharing (Runner.entitlements подключён к конфигурациям Runner).

```powershell
cd mobile
flutter pub get
flutter run --dart-define=API_BASE_URL=https://80.242.213.87
```

Этот IP уже задан в мобильном коде по умолчанию; `--dart-define` позволяет его переопределить. Суффикс `/api` не добавляйте. В release разрешён только HTTPS. Сертификат на IP и серверный маршрут должны быть настроены по инструкции выше.

Для Android-эмулятора и локального Laravel разрешите HTTP только в debug:

```powershell
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000 --dart-define=ALLOW_INSECURE_API=true
```

Этот debug-адрес относится к Android-эмулятору. На телефоне нужен доступный HTTPS-сервер. Для локального HTTP на iOS понадобятся отдельные debug-настройки ATS; production-исключение для прежнего HTTP IP удалено.

После обновления потребуется повторный вход: старый токен из SharedPreferences удаляется; новая сессия хранится в защищённом хранилище ОС. Непереданные итоги тренировок, показания пульса и наблюдения сна сохраняются там отдельно для каждого аккаунта; повторная отправка выполняется при входе/запуске. Во время активного подключения браслета приложение сохраняет валидное показание пульса не чаще раза в 30 секунд. На главном экране отображается серверное среднее последних 10 сохранённых показаний. История тренировок загружается с сервера после входа. Наблюдаемый интервал сна сохраняется даже при неизвестной расшифровке стадий; время сна и Sleep Score в этом случае не вычисляются.

При первом подключении каждых часов выберите подтверждённое семейство SDK на экране подключения. Приложение запоминает этот выбор отдельно для каждого устройства и применяет его автоматически при следующих подключениях, включая переключение между V8 и 2208A. Неизвестной модели нельзя запускать тренировку до подтверждения. Оба SDK используют одинаковый BLE-сервис и базовые команды; имя часов может изменяться, поэтому для безопасного распознавания новых устройств без первого выбора нужен документированный идентификатор модели от производителя.

## Обновление существующего сервера

Установите зависимости из `backend/composer.lock`, выполните миграции с обычной для проекта процедурой резервного копирования и обновите конфигурационный кэш. Миграция `2026_09_25_000001_create_measurements_tables` добавляет таблицы `heart_rate_samples` и `sleep_observations`. Сначала обновляется сервер, затем мобильный клиент: новая сборка вызывает дополнительные API-маршруты.

```powershell
cd backend
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:cache
sudo systemctl restart fitness-api.service
```

Параметры БД, HTTPS и секреты остаются только в серверном `.env`. Не запускайте `migrate:fresh`: он удалит данные. Перед обновлением сделайте резервную копию БД.

## Проверки

```powershell
cd backend
composer validate --no-check-publish
composer audit
php artisan test
```

```powershell
cd mobile
flutter analyze
flutter test
```

Автотесты не подтверждают работу конкретной прошивки, фоновую BLE-связь или физиологическую точность. Проверка на физических V8/2208A и сборки Android/iOS остаются обязательными перед выпуском.
